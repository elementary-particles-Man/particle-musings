OS/VM 概念対応表

社会の各要素をシステムアーキテクチャにマッピングした一覧。
1. VM (仮想マシン) 概念
国家システム

物理的な地球を土台に、法制度、通貨、ルールによって作り出された仮想的な運営空間。

2. Kernel (カーネル) 特権
政府・中央銀行

通貨発行権（信用創造）を有し、法律や予算アロケーションを決定する最上位の特権機関。

3. Userland 領域
民間・企業・家計

特権レベルを持たない普通のプレイヤーが安全に並行プロセスを稼働させる実体市場。

4. Real Memory 物理
実物資源 (労働・時間・エネルギー)

短期的に money だけで変更できない物理制約。長期的には技術やインフラ投資で拡張される。

5. Token 記号
お金 (法定通貨/引換券)

実物それ自体ではなく、物理メモリを一時的に引き当てるための「番号札（アクセス権）」にすぎない。

6. GC (ゴミ回収) 機能

政府の貯金箱ではなく、市場の過剰な購入要求（トークン）を回収消去してインフレを抑える調停機能。

7. Thrashing 例外
インフレーション

実物（メモリ）が足りないのにトークンが多すぎ、やりくり作業に追われて経済が停止（フリーズ）する現象。

8. OOM Killer 致命
